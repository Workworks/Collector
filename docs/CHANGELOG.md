## 📦 [v3.0.0] - 2026-08-20 (VersionCode: 22)

### 🌟 智能化与大屏体验里程碑重磅升级 (阶段一与阶段二全量交付)
- **📸 拍照发票/小票/外包装 OCR 智能识别与秒录入 (`SmartIntakeHelper.kt`)**：
  - 接入 Google ML Kit 离线中文 OCR 引擎；
  - 拍照小票或包装盒，AI 自动毫秒级提取品名品牌、单价、购买日期、保质期到期日与分类并自动填充。
- **💬 自然语言一句话智能记账 (`SmartIntakeHelper.kt`)**：
  - 支持粘贴或输入自然语言（例如“昨天在山姆买了2箱牛奶单价65保质期到10月15日”），AI 自动拆解结构化数值并完成填充。
- **🌐 局域网内置 Web 网页端大屏控制台 (`LanSyncHelper.kt`)**：
  - 手机开启局域网互传后，电脑浏览器访问 `http://手机IP:8848` 即可加载黑曜石大屏 Web 控制台；
  - 支持资产大表格搜索/过滤、网页端快速记账、多选「批量修改放置位置」与「批量删除」，并支持一键导出 CSV 资产表。
- **📋 空间实物沉浸式巡检大盘点模式与差异报告 (`InventoryAuditDialog.kt`)**：
  - 选择目标空间（如“主卧衣柜”或“🌟 全空间所有资产”）开启盲盘；
  - 逐项「确认在位」、「数量修改」或「标记缺失」；
  - 盘点结束自动生成《实物资产盘点报告》，列出完全吻合数与差异清单，并刷新在位打卡时间戳。
- **🤖 闲鱼/转转退役转卖 AI 智能文案与回血定价助手 (`ResaleCopilotHelper.kt`)**：
  - 物品退役时结合原价、使用天数、成色与品牌自动计算**秒出参考价**与**建议挂牌价**；
  - 生成高转化商品文案，一键复制并采纳秒出价，直接打开闲鱼粘贴发布。

## 📦 [v2.9.0] - 2026-08-19 (VersionCode: 21)

### 🌟 六大进阶系统特性全量上线与跨平台多端发布
- **⚡ 局域网免密极速互传 (`LanSyncHelper.kt`)**：
  - 内置轻量 HTTP 局域网微服务（Port 8848），手机生成配对二维码与局域网 IP；
  - 电脑或另一台设备连接同一 Wi-Fi，无需第三方云盘账号即可一秒免密双向同步与数据合并。
- **🖨️ 蓝牙便携标签机直连打印 (`BluetoothPrinterHelper.kt`)**：
  - 原生支持标准 ESC/POS 与 TSPL 打印协议，通过蓝牙 SPP 直连汉印、精臣、得力等便携热敏打印机；
  - 收纳箱二维码弹窗一键直出包含空间名、箱号、在库物品摘要与高清二维码的物理防水标签。
- **🏷️ NFC 智能标签「碰一碰」写卡与零点击寻物 (`NfcHelper.kt`)**：
  - 支持将房间与收纳箱写入标准 NTAG213/215/216 智能 NFC 贴纸；
  - 手机背部碰触收纳箱贴纸，零点击秒级识别并在空间平面图上高亮定位，展开箱内清单。
- **📚 多账本体系与独立空间隔离 (`LedgerManager.kt`)**：
  - 支持建立「个人资产」、「家庭仓储」、「办公物资」及自定义独立账本；
  - 首页顶栏一键快速切换，各账本出入库流水、分类与折旧独立核算。
- **💰 闲置退役变现与回血 ROI 分析 (`ReportFragment.kt`)**：
  - 报表中心新增闲置变现看板，统计闲鱼/转转二手回收总额、资金回收率 % 与真实净支出成本；
  - 推出「🏆 断舍离变现英雄榜」，量化全生命周期物品回血收益。
- **🛒 耗材安全库存预警与智能采购清单 (`DataStore.kt`)**：
  - 消耗品支持设定最低安全库存线；低于安全阈值时首页自动浮现告急预警卡片；
  - 提供「🛒 一键生成采购单」，一键生成格式化待采购清单直发微信或淘宝/京东搜索采购。
- **🐧🍎 Linux 与 macOS 跨平台桌面端正式发布 (`:desktop` 模块)**：
  - 提供 `Collecter-Desktop-2.9.0.jar`、Linux 一键启动包 (`.tar.gz`) 与 macOS 双击直启包 (`.zip`)；
  - 手机端与桌面端数据 100% 同步互通。
