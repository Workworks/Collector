# 账单记账与快速文本录入

## 入口

底部点击“账单”。“提醒”仍可从首页今日事项或“我的 → 处理提醒”进入；原资产报表从账单页右上角“报表”进入。

## 最快的写法

每行一笔，日期只写一次：

```text
@9/26
支出 52 餐饮 小母鸡 #已入账 ; 原价45+配送7
支出 9.9 餐饮 猪肉 ; 10.8/斤
支出 28.82 采购 打包盒 #未入账
支出 50 交通 汽车加油 ; 5.84L +120KM
支出 14.42 交通 汽车充电 ; 峰值0.97kWh +98KM
支出 20USD 订阅 ChatGPT #每月 ; 自动续费
收入 200 退款 采购退款
```

字段顺序：

```text
支出/收入 金额[币种] 分类 项目 #状态/#周期 ; 备注
```

- 日期头：`@YYYY-MM-DD` 或 `@M/D`。不写时使用当天。
- 币种：`CNY`、`RMB`、`元`、`¥`、`￥`、`USD`；不写时为 CNY。
- 状态：`#已入账`、`#未入账`；不写时为已入账。
- 周期：`#每周`、`#每月`、`#每年`。
- 备注：分号 `;` 或 `；` 之后的内容会原样保留。

## 旧手账兼容

“快速粘贴”也会尝试识别以下写法：

```text
9/25晚
采购+40（未入账）

记账9/26
小母鸡: 52->45 +7元
猪肉: -9.9（10.8/斤）
配送: 世贸+8（未入账）
汽车加油: 5.84L 50元，+120KM
汽车充电: 峰值0.97kw/h 14.42元 +98KM
```

兼容写法必须经过预览确认。带负号但没有“收入、退款、报销、收款、返现”等关键词的金额，会按支出金额处理，并把这一判断写入备注。没有明确金额的行会列为“不会保存”，不会生成 0 元账单。

## 操作

1. 点击“快速粘贴”，输入或从剪贴板粘贴手账。
2. 点击“解析预览”，核对日期、项目、金额、币种和待入账状态。
3. 未识别行会单独列出；确认后只保存已识别账单。
4. 点击账单可编辑；点击“未入账”可直接确认入账；垃圾桶按钮会先要求确认。
5. 只想快速记一笔时，点击“手动记账”，只填项目和金额即可保存。

## 数据说明

- 金额以“分”为整数保存，避免小数累计误差。
- CNY 与 USD 分开汇总，不自动使用未知汇率换算。
- 账单保存在本机私有沙盒，并随完整备份、WebDAV 和局域网合并进入 `bills` 集合。
- APP 不读取银行、支付平台、短信或系统通知。
