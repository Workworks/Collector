# 收集与物品工作台

## 打开与日常使用

Android：我的 → 收集箱 → 整理工作台，也可从教程中的“统一整理工作台”进入。
Windows JVM 开发版：菜单“整理工作台”→“收集、找回与生命周期”。这是当前可用入口，不等同于 Native 安装器已经交付。

1. 收下文字或链接，重复原文会提示，仍可保留另一份。照片继续使用 Android 分享入口；桌面可选文件或拖入文件，确认后复制到本机收集箱，原文件不删除、不自动上传。
2. 输入关键词（空格组合）及位置找回记录；空条件显示全部。常用查询可保存，目前最多 100 个。
3. 勾选记录后批量修改位置、标签和责任人。一次最多 500 条，缺失记录或字段无效时整批不提交。桌面还可修改备注。
4. 提取建议只识别已有原文/OCR 中明确的金额、日期和型号，先预览、再保存到辅助字段；不自动覆盖原文、价格或凭证内容，不调用远程模型。
5. 单条详情可查看生命周期与关联资料，建立物品和发票/说明书的双向关联。不同账本的同名 ID 按账本区分。
6. 生命周期可记录购买、维护、借出、归还、转卖和报废。借出必须写借用人；借出中先归还，不能直接转卖；转卖/报废后不能继续追加普通操作。填写下次维护日期可进入 Android 现有每日提醒检查；实际长时系统调度仍待真机验收。

标签、责任人与生命周期是共享扩展字段，不代表每个旧专业馆的独立业务表单都已改造。工作台保留旧字段和原件；不要把“记录维护完成”当成自动完成所有专业馆业务。

## 备份与恢复

Android“备份/家庭”、桌面“本地备份”菜单均提供加密导出、解密预览、确认恢复、备份状态和只读冲突查看。

- 加密备份扩展名 `.collecter`，密码至少 12 字符，建议使用不重复的长口令并另处保管；**忘记密码无法代为恢复**。没有后门或服务端托管密钥。
- 使用随机盐、随机 nonce、PBKDF2-HMAC-SHA256（600000 次）和 AES-256-GCM（128-bit tag），格式头参与认证。错误密码、篡改、未知格式或超限输入在导入前拒绝。
- 加密/解密在后台执行；模拟器测试显示运算可能较慢，不要因等待而反复提交。明文 JSON 备份、当前本地数据库和原 WebDAV 上传不会自动改为加密。
- WebDAV 历史入口只适用于提供 `history-etag-v1` 接口的相邻服务；读取已有配置，列出版本，预览后只恢复到本机，**不覆盖远端最新备份**。其他服务不支持时明确报错。
- `_conflicts` 目前只读展示，不自动选择冲突版本。离线后可显式重试原上传动作；没有后台永久重试队列。

加密参数参考 [OWASP 密码派生建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) 和 [Java GCM 参数说明](https://docs.oracle.com/en/java/javase/24/docs/api/java.base/javax/crypto/spec/GCMParameterSpec.html)。算法使用平台实现，不自行实现密码算法。

## 家庭权限

Stage 456：Android 已允许可信局域网连接；家庭接口 HTTP 地址只接受私有 IPv4 或 localhost，公网必须 HTTPS，不支持用任意公网 HTTP 域名传成员密钥。会话到期后可以重新签发，旧授权不会自动继承；需重新授权新成员 ID。

桌面工作台“家庭权限”可签发成员会话密钥，选择 viewer（只读）或 editor（整理、维护、借还）。再选择记录，将该成员 ID 写入共享范围。默认无共享；敏感标记及证照集合不进入家庭接口。

Android 在“备份/家庭 → 连接家庭工作台”输入完整 `/api/v1/family` 地址及成员密钥，查看授权记录；编辑者可以修改位置。不要输入或分享所有者配对密钥。

- 默认服务仅本机。跨设备必须显式 `--lan` 启动，并使用可信局域网；HTTP 不加密，不要把此端口直接发布到公网。
- 成员密钥在 12 小时、撤销或应用退出后失效，不写入业务备份。重新签发会生成新的成员 ID，需要重新授权记录。这是会话协作，并非永久家庭账号体系。
- 查看者不可写；编辑者不能改变共享/敏感标记，不能操作未共享记录，不能读取全量备份；服务端实施限制，界面隐藏不是权限边界。
- 修改记录附带成员 ID、操作和时间。此日志不是防所有者篡改的合规审计链。
- 本机 OS 账户能访问本地文件；敏感标记不等于数据库加密或独立应用锁。
