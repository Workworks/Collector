## 修复

1. `WebDavSyncHelper.kt`：Android 使用 HEAD 代替不受支持的 PROPFIND；PUT/GET 保留完整备份、大小限制和条件写入。404 只说明备份尚不存在，不代表已经验证写权限。
2. `DesktopWebDavHelper.kt`：桌面用支持扩展方法的 HttpClient 探测；PUT/GET 禁止重定向；下载记住 ETag，随后上传可带 If-Match，远端变化仍拒绝覆盖。
3. `HotPatchEngine.kt` / `DexSignatureVerifier.kt`：安装和启动加载前 SHA256withRSA 强验签，缺钥、缺签名、无效编码、错误密钥、篡改均拒绝。APK 签名密钥不自动当作 DEX 密钥。
4. `PatchArchive.kt`：规范路径边界检查外，拒绝绝对路径、反斜线穿越、盘符/ADS；保持 512 条目和 64 MiB 解压上限。
5. `VaultSchemaMigration.kt` / `WireAliases.kt`：一次性原子合并两条分支的工具、绿植、宠物、饮品存储键及日期/进度别名；保留旧键和未知字段，标记成功后不重复导入已删除记录。饮品余量保留小数。转卖/订阅统一到已持久化的 `retiredAt` / `purchaseDate`。
