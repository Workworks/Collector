# Stage 457：整合本地与远端、修复安全与 WebDAV

用户授权整合全部本地/远端变动、提交并保持远端最新；本轮不创建新版本或 Release。

## 目标与边界

以远端 v4.3.6/main 与本地工作区共同形成整合树，保留远端新增模块/设置视口和本地 shared/备份/工作台/家庭功能。以 4.3.6/43 为现有版本基准，不另升版。保留包名、存储键、原签名外置配置；禁止将 keystore、业务数据、凭据、构建缓存提交。先保存本地快照，再整合；不覆盖丢弃用户工作。
