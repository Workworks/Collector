# Stage 467：搜索找回卡

日期：2026-09-05。

## 目标

让统一搜索从“看到结果”前进到“立即找到并打开资料”：主资产结果可点击，集中展示位置、备注、实物照片、发票/保修卡及关联记录。

## 边界

- 不迁移数据，不自动建立或删除关联。
- 复用现有 `links` 双向关联、资产照片和发票沙盒路径。
- 图片仍由现有私有沙盒预览器读取，不产生上传行为。
- 本 Stage 不提高版本号，不发布。

## 完成标准

- [x] AC-01：主资产搜索结果带稳定引用并可点击。
- [x] AC-02：找回卡显示名称、分类、位置和备注，缺失字段给出清晰状态。
- [x] AC-03：实物照片与发票/保修卡可从找回卡打开。
- [x] AC-04：双向关联资料显示名称并可继续打开，删除原记录时不修改其他记录。
- [x] AC-05：摘要逻辑单测、Release 构建和 selfcheck 通过。
