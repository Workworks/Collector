# Stage 458：移动端更新下载 TLS 热修复

日期：2026-09-01。触发：v4.3.7 发布后用户报告移动端提示 `Chain Validation failed`。

## 目标与边界

不关闭 TLS 校验、不信任用户证书、不绕过 Android 安装签名。移除全部第三方代理：其中两个证书过期或握手失败，ghfast 在 Android 14 实测返回 HTTP 403。仅使用 GitHub 官方源。解析 GitHub asset digest，对下载内容统一做 SHA-256 和大小校验。下载失败显示具体结果；TLS 错误提示检查系统日期时间，并提供官方 URL 的系统浏览器入口。

完成代码和门禁后发布 4.3.8 / 45 hotfix；applicationId 与原签名不变。v4.3.7 用户无法从失败界面获得新代码，因此同时保留 GitHub 官方手动下载链接作为启动路径。

## 验收标准

- AC-01：候选源仅包含 GitHub 官方地址，第三方代理没有残留。
- AC-02：下载文件大小及 GitHub SHA-256 不符时删除并尝试下一源，缓存也必须复核。
- AC-03：失败界面不只显示最后一个错误，证书链失败给出日期时间提示和官方浏览器入口。
- AC-04：单测、完整自检、原签名、v4.3.7 → 4.3.8 数据保留升级通过。
- AC-05：正式 Release 附件回读哈希一致。
