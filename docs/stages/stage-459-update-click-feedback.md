# Stage 459：移动端更新点击无反馈修复

## 问题

v4.3.8 在未命中预下载缓存时，主更新按钮会关闭版本弹窗并进入应用内 GitHub 直连下载。部分移动网络连接长时间没有有效数据，用户只感知到弹窗消失，既没有进入系统安装器，也无法立即选择其他路径。

## 范围

- 未缓存 APK 时，主按钮改为立即通过系统浏览器打开 GitHub 官方 APK。
- 点击后先显示可见提示；没有可用浏览器或启动失败时显示明确错误。
- 应用内下载保留为标注明确的备用入口，并继续使用进度、失败原因与摘要校验。
- 已验证缓存仍直接进入原签名 APK 安装流程。
- 不修改 TLS、签名、摘要校验或 `applicationId`。

## 验收标准

- AC-01：未缓存更新的主按钮不会进入无反馈后台线程，而是打开系统 chooser/浏览器。
- AC-02：应用内下载仍可由用户显式选择，开始时立即显示进度弹窗。
- AC-03：浏览器不可用或启动异常有用户可见错误。
- AC-04：单元测试、Release 构建与原 selfcheck 全部通过。
- AC-05：版本号不变；只有用户明确授权发布后才能升级至下一 patch。
