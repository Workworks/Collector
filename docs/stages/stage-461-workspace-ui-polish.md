# Stage 461：工作台入口与收集箱弹窗视觉优化

## 问题

“我的”页顶部入口缺少语义图标，深色主题下按钮文字对比度不稳定。点击“收集箱”后使用系统默认列表对话框；空数据时主体留下大面积空白，三个文字操作散落在右侧，缺少清楚的主次层级。

## 修复

- 顶部三个入口增加收集、搜索、提醒语义图标，固定白色按钮文字，并把圆角收紧为 14dp。
- 新增 `dialog_collection_workspace.xml`，使用与主页面一致的卡片、颜色和圆角体系。
- 空收集箱显示完成状态、说明文案；有记录时显示可滚动的紧凑记录列表。
- “收下文字或链接”作为唯一实心主按钮，“打开整理工作台”作为描边次按钮，关闭操作移入标题栏。
- 保留原有新增、查看记录和打开工作台行为。

## 验收

- Android 14、1080×2400 临时 AVD 实际打开“我的”页及空收集箱，顶部文字对比度、弹窗空状态与按钮层级均符合预期。
- Debug 构建成功；原 selfcheck 6/6，Android 69 项测试 0 失败，187 个模块全部记录。
- 截图和自检证据位于 `docs/stages/evidence-461/`；临时 AVD 已删除。
