## 目标与决策

产品继续围绕离线收藏、资产生命周期和可恢复备份发展。优先防丢失、防误覆盖；不新增专业馆、不做通用 AI、macOS 或整体 UI 重写。这些方向由本轮决策暂缓，不宣称实现完成。

## 边界与工作包

- WP-01：相邻 WebDav 服务为 `Collecter_Backup.json` 增加历史、删除恢复、ETag 条件写入。其他文件维持现有 WebDAV 行为。历史位于挂载目录之外；不自动清理历史，不触碰生产备份。目录删除和 MOVE/COPY 不得绕过保护。旧客户端无条件 PUT 仍兼容，但历史可恢复；条件写入拒绝过期快照，不自动合并业务数据。
- WP-02：检查并补齐客户端条件写入及可自动化验收，新增测试不得修改旧断言以伪造通过。
- WP-03：重新检查发布、原生工具链及固定域名前置；可执行则交付，缺失则保留 BLOCKED，不更改包名、绕过签名或把 JVM 包当原生安装器。
- WP-04：运行项目门禁、备份压力与安全测试，更新说明、任务和阶段证据。真机、独立网络、第三方 UI 和长期调度不能由单测替代。
