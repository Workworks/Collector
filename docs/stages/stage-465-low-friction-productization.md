# Stage 465：低门槛产品化 P0–P3

日期：2026-09-03。用户授权按优先级完成 P0–P3 全部任务。

## 目标

把 Collecter 的默认体验收敛为“记得住、找得到、不过期”：无需理解账本和专业馆即可收集、查找、处理提醒，并在需要时逐步进入模板、家庭协作和批量导入。

## 边界与不变量

- Android 为本轮主要交互端；桌面只补家庭配对输出，不修改无关桌面功能。
- 复用现有 `Entry`、`CollectionWorkspace`、备份、家庭权限和通知模型，不迁移或删除用户数据。
- 默认导航只展示资产、收集箱、提醒、我的；高级功能仍可从“更多功能”进入。
- 家庭分享继续由桌面签发成员身份并限制共享记录；二维码不得包含所有者密钥。
- 通知只由实际到期、临期、长期未归位或待整理积压触发，并沿用去重状态。
- 本 Stage 不提高版本号，不创建 Release。

## 工作包

- WP-01（P0）：首问四入口、名称快速保存及未整理默认位置、四核心导航、照片/整理/提醒一步提示。
- WP-02（P1）：多格式收集箱、五种场景模板、基于名称/扫码/历史的默认建议、首页价值反馈、统一搜索、三档提醒。
- WP-03（P2）：家庭二维码配对、相册/CSV/备份/连续扫码导入、轻量进度、价值型通知。
- WP-04（P3）：用户可见产品表达统一为“记得住、找得到、不过期”。
