# Stage 453：Collecter 可靠性与核心使用闭环
日期：2026-08-30。状态：PARTIAL；原生交付 BLOCKED。用户已授权按 product-direction 的优先级完成全部非暂缓任务。

## 目标与范围
在现有 Android 与 Windows 代码上完成安全恢复、安全局域网访问、完整双端同步、统一收集箱、关联查找、可操作提醒和单一桌面启动流程。保留离线能力、安装标识、现有数据键、历史兼容和版本号。实际目录由用户改为 Collector（产品名仍为 Collecter），不再自动重命名。

不包含：新增专业馆、通用 AI 聊天、macOS 发布、复杂悬浮窗、大规模视觉重写、购买证书、生产发布、访问真实业务数据。所有运行测试使用临时数据目录；不自动接入家庭网络或云盘。

## 工作包与完成标准
- WP0A 安全恢复：先校验再提交，拒绝无效/超限输入；原子替换文件；Android 全集合与附件备份；导入前显示数量与风险并可取消。
  - AC01：无效 JSON、错误集合类型、重复 ID、非法附件路径、超限附件不会改动原数据。
  - AC02：所有本地集合和引用附件可恢复到全新隔离目录；旧版备份保留缺失集合。
  - AC03：本地/WebDAV 恢复均需用户确认，失败给出可见反馈。
- WP0B 本地服务：默认回环监听、显式启用局域网、未授权请求拒绝、HTML 转义、请求大小限制、关闭释放端口和线程。
  - AC04：真实 HTTP 回归验证匿名/错误凭据无法读写、授权请求可用、跨来源请求拒绝、关闭后不可访问。
  - AC05：恶意 HTML 仅作为文本渲染；版本来自构建信息；所有输入读取有大小限制。
- WP1A 数据契约：共享纯 Kotlin JSON 契约及字段保留，含删除标记、编辑时间、幂等合并与冲突反馈。
  - AC06：全集合/全字段双向往返保留，证照/想法/剪藏均覆盖，旧字段默认值兼容。
  - AC07：重复合并不重复，已删除记录不复活，并发编辑有确定规则及可见报告。
- WP1B 收集箱：文字/链接/照片先落盘，后分类；用户可重试处理；原始内容保留。
  - AC08：Android 分享入口与应用内入口可访问；图片复制到私有目录；失败不丢原件；不默认要求全盘截图权限。
- WP2A 关联：物品与资料双向关联，统一搜索可跳转，解除关联不删除记录。
  - AC09：建立、查询、解除关联的持久化测试通过；应用入口可操作。
- WP2B 提醒：完成、延后、关闭与去重。
  - AC10：状态跨重启保留；同事项同周期不重复发送；新周期能再次提醒。
- WP3 桌面：明确一个主要启动路径，壳与引擎生命周期协调，打包失败明确退出。
  - AC11：版本与产物一致，缺依赖/编译失败不能假成功；安装目录与用户数据分离。
  - AC12：Windows 安装/升级/退出与 Android 设备冒烟验证有真实证据，不以单测代替。
