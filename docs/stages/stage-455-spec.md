# Stage 455：物品与资料的完整工作流

2026-08-31。用户授权自主决策，实施上轮提出的七个演化方向。保持离线核心、现有包名/签名/版本和已有用户修改；不以新增专业馆或整体换 UI 扩大范围。

## 目标与工作包

1. 收集整理：统一工作台快速收集，重复提示、批量标签/位置整理；从已有原文/OCR 中提取金额、日期、型号建议，确认后应用，绝不自动覆盖原件或删除重复项。
2. 找回：跨集合关键词、位置筛选、保存搜索；单条汇总关联资料和生命周期。新增数据保留未知字段，旧备份仍可导入。
3. 生命周期：购买、维护、借出、归还、转卖、报废事件与责任人/说明，追加历史；用规则阻止无借出记录的归还等无效状态变化。维护记录可保存下次日期；实际通知不冒充已完成长期验收。
4. 备份：可见状态与失败信息、历史访问入口；加密本地备份两端互通，密码错误/篡改不改本地数据；备份密码由使用者保管，不设后门恢复。保留现有 WebDAV 条件上传，断网仅显式重试，暂不后台自动覆盖。
5. 桌面：可实际操作的整理窗口，搜索快捷键、批量编辑、文件拖入（复制到私有目录）；复用原生架构不替代 Native 安装门禁。
6. 家庭：桌面所有者显式签发每成员会话访问密钥、查看者/编辑者角色、撤销；只访问明确共享且非敏感的记录。服务端校验读写权限，成员不能访问全量备份/API。个人标签不等于权限。局域网 HTTP 只供可信网络，不默认开放。
7. 隐私与规模：加密导出、敏感记录不进入家庭视图；测试固定数据集搜索/批量编辑，暂不无证据迁移数据库。宿主设备账户自身的访问保护不由界面隐藏替代。

## 实施与验证边界

shared 提供纯 Kotlin 工作流与加密逻辑；Android/desktop 接入真实仓储和入口。新增收藏搜索等集合进入 BackupDocument、Android 映射及共享同步，成员会话密钥不进入备份。涉及批量操作先校验全部目标再一次提交。家庭远程编辑写入审计事件。
