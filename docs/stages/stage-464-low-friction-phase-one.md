# Stage 464：降低使用门槛第一阶段

日期：2026-09-02。

## 目标

新用户无需理解分类、空间和专业馆，即可从首页完成第一次记录，并持续通过收集箱、统一搜索和今日事项获得价值。

## 边界

- 范围内：Android 首次引导、名称快速保存、首页收集箱入口、统一搜索入口、今日事项常驻状态。
- 范围外：不改数据结构、applicationId、桌面业务、WebDAV、发布版本号和专业馆能力。
- 兼容性：快速保存仍写入现有 `Entry` 主库；默认分类为“通用”、数量 1、单位“件”，完整编辑入口继续保留。

## 工作包

- WP-01：一次性极简引导，仅提供“记一件、先收集、搜索、稍后”四个动作。
- WP-02：名称快速保存，空名称拒绝，其他字段使用安全默认值。
- WP-03：首页增加醒目的收集箱、搜索和快速记录入口，并显示待整理数量。
- WP-04：恢复真正的跨库统一搜索，不再错误跳转到工作台搜索。
- WP-05：今日事项即使为空也常驻首页，明确反馈“今天无需处理”。
