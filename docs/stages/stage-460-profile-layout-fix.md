# Stage 460：「我的」页顶部入口排版修复

## 现象

窄屏设备上，“我的”页顶部三个工作台入口几乎贴在一起；MaterialButton 默认水平内边距挤压中间按钮，导致“找回与关联”换成两行，整行高度不一致。

## 根因

入口栏由 `ProfileFragment` 在运行时动态插入，无法在布局预览中检查；三个等宽按钮没有单行限制、窄屏字号适配和按钮间距，并继承 MaterialButton 默认 inset 与 padding。

## 修复范围

- 将三个入口迁入 `fragment_profile.xml`，使结构与约束可预览、可检查。
- 三个按钮继续等宽，增加 8dp 按钮间距及 48dp 触控高度。
- 文案限制为单行，在 12sp 至 14sp 间自动适配；移除会挤压中文的默认 inset，保留 4dp 内容内边距。
- 不改入口文字、点击行为、主题色和页面其他卡片。

## 验收标准

- AC-01：“收集箱”“找回与关联”“处理提醒”均保持单行。
- AC-02：三个入口等宽且存在稳定间距，最小触控高度为 48dp。
- AC-03：原有三个点击行为保持不变。
- AC-04：Debug/Release 编译及原 selfcheck 全部通过。

## 验收结果

- AC-01 至 AC-03：PASS。Android 14、1080×2400 临时 AVD 实际打开“我的”页，三个按钮均为单行、等宽、等高，间距稳定；页面卡片未发生新的截断或错位。
- AC-04：PASS。Debug 构建成功；原 selfcheck 6/6，Android 69 项测试 0 失败，187 个模块全部记录。
- 截图与自检原始证据位于 `docs/stages/evidence-460/`；临时 AVD 已删除。
