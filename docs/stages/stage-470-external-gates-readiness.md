# Stage 470：外部交付门禁准备清单

日期：2026-09-05。状态：`READY / BLOCKED`。

本清单按用户确认的顺序执行。没有前置条件时只完成隔离环境和验收步骤准备，不修改正式数据或绕过安全门禁。

## A. 实体 Android 与移动网络

前置：两台可解锁 Android 手机、USB 调试、至少一张可用蜂窝网络 SIM。

1. 手机 A 从正式 v4.3.9 写入升级哨兵并覆盖安装 v4.3.10；确认版本、数据、附件和冷启动。
2. Wi-Fi、蜂窝网络分别检查更新并下载；记录 GitHub API、官方资源或镜像实际命中来源。
3. 两台手机完成家庭二维码配对；验证查看者、编辑者、敏感记录隔离和撤销后 401。
4. 验证锁屏凭据、生物识别、后台 60 秒重锁、厂商省电和通知时序。

当前：`BLOCKED`，`adb devices -l` 仅有 API 34 模拟器。

## B. 固定 WebDAV 域名

前置：Cloudflare 账户中的受管域名和 Tunnel 管理权限。

1. 保留本地 WebDAV 数据目录和鉴权，建立受管 Tunnel；凭据只进入主机密钥存储。
2. 固定 HTTPS 域名执行未认证 401、认证 PROPFIND 207、HEAD、PUT、GET、ETag 条件覆盖和附件恢复。
3. 配置主机自启动、健康检查、证书/隧道失效告警及域名切换手册。

当前：`BLOCKED`，只有临时 Quick Tunnel，不把临时 URL 写入产品默认值。

## C. 加密迁移与持久上传队列

前置：至少一台带真实锁屏凭据的手机、可恢复备份、损坏密文回滚环境。

1. 先生成并验证恢复点，再迁移 WebDAV 凭据和业务库；任一步失败恢复原数据。
2. 覆盖首次加密、升级迁移、凭据失效、密文损坏、锁屏变更和恢复取消。
3. 在加密恢复通过后启用持久上传队列；离线重试、幂等、冲突暂停和人工确认必须可见。

当前：`BLOCKED`；不会在缺少恢复环境时对现有数据静默迁移。

## D. Windows 干净机与代码签名

前置：第二台干净 Windows 11 x64 主机、受信 OV/EV 代码签名证书。

1. 核对 v4.3.10 ZIP 哈希，验证首次启动、WebView2 探测、退出、升级和数据保留。
2. 对 Native Host/安装器签名并验证证书链、时间戳和 SmartScreen 行为。
3. 回下载已签名产物，核对签名与发布摘要。

当前：本机 Native smoke 为 0；干净机与受信签名 `BLOCKED`。
