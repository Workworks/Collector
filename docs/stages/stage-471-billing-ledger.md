# Stage 471：账单记账与快速文本录入 Spec

状态：`COMPLETED（已发布 v4.3.11）`。完成日期：2026-09-26。发布日期：2026-09-27。

## 1. 目标

在 Android 端提供独立账单模块，让用户能够手动记录日常收支，也能把手机手账中的多行文本一次粘贴、预览并批量保存；账单数据保持本地离线，并进入现有完整备份、WebDAV 与跨端保真链路。

模块放在底部第三个核心入口，将当前“提醒”入口调整为“账单”。提醒仍可从首页今日事项和“我的 → 处理提醒”进入；原资产报表从账单页右上角进入。这样记账保持一键可达，同时不增加第五个核心导航项。

## 2. 快速文本格式

推荐格式以日期头开场，每行一笔：

```text
@2026-09-26
支出 52 餐饮 小母鸡 #已入账 ; 原价45+配送7
支出 9.9 餐饮 猪肉 #已入账 ; 10.8/斤
支出 28.82 采购 打包盒 #未入账
支出 50 交通 汽车加油 #已入账 ; 5.84L +120KM
支出 14.42 交通 汽车充电 #已入账 ; 峰值0.97kWh +98KM
支出 20USD 订阅 ChatGPT #每月 ; 自动续费
收入 200 退款 采购退款 #已入账
```

规则：

- 日期头支持 `@YYYY-MM-DD`、`@M/D`；没有日期头时使用当天。
- 正文顺序为 `支出/收入 金额[币种] 分类 项目 #状态/#周期 ; 备注`。
- 币种支持 `CNY/RMB/元/¥/￥` 与 `USD`，缺省为 CNY；不同币种分别汇总，不自动换算。
- 状态支持 `#已入账`、`#未入账`，缺省为已入账；周期支持 `#每周`、`#每月`、`#每年`。
- `;` 后全部作为备注保留；金额以最小货币单位整数保存，避免浮点累计误差。
- 兼容常见手账写法：`9/26`/`记账9/26` 日期头、`项目: 20USD`、`采购+40（未入账）`、`52->45+7元`、`5.84L 50元 +120KM`。兼容解析只作为预览建议，未识别行不保存并明确列出。

## 3. 影响范围与边界

### 范围内

- 共享层：纯 Kotlin 文本解析器、日期/金额/状态/周期解析与单元测试。
- Android：账单模型、本地存储、月度汇总、账单列表、手动新增/编辑/删除、待入账确认、快速文本预览与批量保存。
- 导航：底部第三入口为“账单”；提醒和资产报表保留替代入口。
- 备份：新增 `bills` 集合，纳入完整备份、恢复、WebDAV、局域网合并和桌面端未知字段保真。
- 文档：快速格式说明、当前 Stage 与 TODO 同步。

### 范围外

- 不接入银行、支付平台、短信或通知读取权限。
- 不进行汇率换算、预算预测、云端 OCR 或自动消费画像。
- 不把账单混入资产 `Entry`，不改变已有多资产账本语义。
- 本 Stage 不新增桌面端账单编辑界面；桌面端必须无损保留并可备份/恢复 `bills`。
- 不修改 `applicationId`、签名、版本号或更新安全策略。

## 4. 设计方向

- 色彩沿用现有翡翠绿、暖琥珀与 Slate 明暗主题，不引入新的品牌色。
- 顶部使用“月度账单纸带”呈现已入账支出、待入账与笔数；金额使用等宽数字特性。
- 主操作只有“快速粘贴”和“手动记账”，列表以日期分组、金额右对齐；待入账使用琥珀状态胶囊。
- 动效沿用现有轻量按压与弹框淡入缩放，避免连续装饰动画。

## 6. 验证方式

- 共享解析：`./gradlew :shared:test`，断言日期头、CNY/USD、状态、周期、截图兼容行、未识别行和金额精度。
- Android 数据：`./gradlew testReleaseUnitTest`，断言 JSON 往返、旧备份缺少 `bills` 的兼容默认值、完整备份包含账单。
- 跨端：`./gradlew :desktop:test`，断言桌面读写其他集合时 `bills` 不丢失。
- 构建：`./gradlew assembleRelease`。
- 整体门禁：`pwsh -File .\tools\selfcheck.ps1`。
- 界面：API 34 模拟器验证亮/暗主题、窄屏、快速粘贴预览、保存、编辑、待入账确认、删除和返回路径；未执行的真实设备操作标记 `BLOCKED`。
