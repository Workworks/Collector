## 1. 产品简介

**Collecter** 是一款专为追求极致收纳秩序与资产全生命周期管理的 Android 原生客户端。它不仅能帮助你记账，还能帮你计算每一件数码产品的**日均折旧成本**（元/天）、监控食品药品**保质期临期预警**、绘制可视化**家庭空间平面图打点寻物**、生成**收纳箱专属二维码标签**，并提供**桌面小组件**、**生物识别隐私锁**与 **WebDAV 私有云多端同步**。

## 2. 核心功能模块使用指南

### 2.1 资产全景看板 (首页)
- **双模态切换**：顶部药丸标签随时切换「物品」与「订阅」两大资产池。
- **关键财务指标**：
  - **总资产估值**：在库在役资产的真实净值汇总；
  - **日均使用成本 (元/天)**：自动按折旧资产的购入天数平摊计算（如：¥6999 的笔记本电脑使用了 1917 天，日均仅 ¥3.65/天）。
- **多维筛选排序**：支持按「在役/退役状态」、「拥有天数」、「总价估值」、「日均成本」及「分类」快速筛选。

### 2.2 物品管理分类
在记一笔或编辑界面中，支持 4 维管理类型细分：
1. 📉 **折旧资产**（如电脑、相机、手机、手表）：按拥有天数动态计算日均折旧损耗。
2. ⏳ **保质期物品**（如药品、护肤品、食品特产）：支持选择 30天/半年/1年/2年/3年 快速标签，列表显示临期倒计时预警。
3. 🛋️ **长期耐用品**（如实木家具、乐器、纪念品）：仅记录拥有天数，不计折旧费。
4. 📦 **日常消耗品**（如纸尿裤、咖啡豆、纸巾）：关注库存数量与单件成本。

### 2.3 实物照片与发票/保修卡留存
- **实物照片**：点击「+ 实物照片」插槽，从相册选择高清实物图，列表卡片自动以圆角封面呈现。
- **购买凭证**：点击「+ 发票/保修卡」插槽，上传电子发票凭证或保修单照片，卡片右下角点亮「🧾 凭证」徽章。
- **全屏沉浸预览**：点击任意缩略图或凭证徽章，直接调起全屏查看器，支持多指缩放与系统分享。

### 2.4 空间平面图、收纳箱二维码与智能扫一扫
- **由物找空间（一键穿梭）**：在首页卡片点击「📍 主卧 · 衣柜」，平面图自动弹出，所属空间自动切换，对应房间呈现高亮边框，物品打点处呈现**金色呼吸脉冲打点光晕 (Pulsing Pin)**。
- **由空间看物品（资产抽屉）**：在平面图点击任意房间，底部自动滑出该房间存放的全部物品清单，点击条目可直接编辑。
- **🏷️ 生成收纳箱二维码标签**：在房间物品抽屉点击「🏷️ 生成二维码标签」，即可生成专属卡片，支持**保存至系统相册**与**一键分享打印**，贴在箱体上。
- **📷 智能扫一扫**：首页顶栏点击扫一扫，对准收纳箱二维码秒查箱内清单；扫描商品条形码（EAN-13 等）自动匹配库内资产或快速入库。

### 2.5 周期订阅资产追踪
- 纳管 iCloud、ChatGPT Plus、宽带、流媒体年卡等周期订阅。
- 自动折算**月均支出**与**年化支出**。
- 支持到期前 1~3 天发送系统通知栏扣费预警。

### 2.6 物品在役/退役与待办归置
- 物品闲置或损坏时，点击「更多 ➔ 物品退役与待办归置」。
- 选择归置方案：`📦 挂闲鱼代售` / `📱 挂转转二手` / `🎁 赠送亲友` / `🗄️ 封箱入库` / `♻️ 环保回收` / `🗑️ 报废`。
- 记录出掉回血金额，回血收益自动计入报表统计。

### 2.7 数据报表、动态环形图与断舍离闲置雷达
- **动态环形图 (Donut Chart)**：分类资产占比原生 Canvas 矢量渲染，触碰扇区即可高亮并显示中心分类总额与百分比。
- **🧹 闲置资产与断舍离雷达**：
  - 自动核算「资产健康度评分」（满分 100 分）；
  - 智能识别超过 180 天未打卡确认在位的闲置品或临期消耗品；
  - 提供「✅ 确认在位」与「📦 一键挂闲鱼/归置」快捷通道。

### 2.8 桌面小组件 (App Widgets)
- **临期预警与订阅倒计时小组件**：放置在手机主屏幕，一眼掌握即将到期的食品药品与近期扣费订阅。
- **资产看板与快捷记一笔小组件**：实时展示在役资产净值与日均消费，点击「+」一秒直接弹出记账界面。

### 2.9 生物识别指纹/面容隐私锁
- 进入「我的 ➔ 更多设置 ➔ 🔐 生物识别隐私锁」开启。
- 开启后，冷启动与切回前台时自动调起指纹/面容验证，全面保护财产与贵重资产位置隐私。

### 2.10 WebDAV 私有云同步与 CSV 备份导出
- **WebDAV 私有云同步**：支持坚果云、Nextcloud、群晖 Synology 等标准网盘，一键配置 URL、用户名与独立密码，支持测试连接、云端上传与一键恢复。
- **Excel 兼容 CSV 导出**：一键生成带 UTF-8 BOM 的资产总表与流水明细，支持系统分享至微信或电脑。

## 3. 调试与模拟器运行指南

### 3.1 命令行启动模拟器
```bash
# 启动 DiaperPhone Pixel 6 模拟器
emulator -avd DiaperPhone
```

### 3.2 常用 ADB 指令
```bash
# 查看已连接设备
adb devices

# 编译并安装最新 Release APK
.\gradlew.bat assembleRelease
adb install -r app/build/outputs/apk/release/app-release.apk

# 启动应用
adb shell am start -n com.kfaino.diapertracker/.MainActivity

# 查看应用日志
adb logcat -s Collecter DiaperTracker
```
