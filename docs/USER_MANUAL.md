## 1. 产品简介

**Collecter** 是一款专为追求极致收纳秩序与资产全生命周期管理的 Android 原生客户端。它不仅能帮助你记账，还能帮你计算每一件数码产品的**日均折旧成本**（元/天）、监控食品药品**保质期临期预警**、绘制可视化**家庭空间平面图打点寻物**，并纳管你的所有周期订阅支出。

## 2. 核心功能模块使用指南

### 2.1 资产全景看板 (首页)
- **双模态切换**：顶部药丸标签随时切换「物品」与「订阅」两大资产池。
- **关键财务指标**：
  - **总资产估值**：在库在役资产的真实净值汇总；
  - **日均使用成本 (元/天)**：自动按折旧资产的购入天数平摊计算（如：¥6999 的笔记本电脑使用了 1917 天，日均仅 ¥3.65/天）。
- **多维筛选排序**：支持按「在役/退役状态」、「拥有天数」、「总价估值」、「日均成本」及「分类」快速筛选。

### 2.2 物品管理分类
在记一笔或编辑界面中，支持 4 维管理类型细分：
1. 📉 **折旧资产**（如电脑、相机、手机、手表）：按拥有天数动态计算日均折旧损耗。
2. ⏳ **保质期物品**（如药品、护肤品、食品特产）：支持选择 30天/半年/1年/2年/3年 快速标签，列表显示临期倒计时预警。
3. 🛋️ **长期耐用品**（如实木家具、乐器、纪念品）：仅记录拥有天数，不计折旧费。
4. 📦 **日常消耗品**（如纸尿裤、咖啡豆、纸巾）：关注库存数量与单件成本。

### 2.3 实物照片与发票/保修卡留存
- **实物照片**：点击「+ 实物照片」插槽，从相册选择高清实物图，列表卡片自动以圆角封面呈现。
- **购买凭证**：点击「+ 发票/保修卡」插槽，上传电子发票凭证或保修单照片，卡片右下角点亮「🧾 凭证」徽章。
- **全屏沉浸预览**：点击任意缩略图或凭证徽章，直接调起全屏查看器，支持多指缩放与系统分享。

### 2.4 空间平面图与寻物高亮穿梭
- **由物找空间（一键穿梭）**：在首页卡片点击「📍 主卧 · 衣柜」，平面图自动弹出，所属空间自动切换，对应房间呈现高亮边框，物品打点处呈现**金色呼吸脉冲打点光晕 (Pulsing Pin)**。
- **由空间看物品（资产抽屉）**：在平面图点击任意房间，底部自动滑出该房间存放的全部物品清单，点击条目可直接编辑。
- **多空间与房间定制**：支持自由创建「自己的家」、「父母家」、「办公室」、「汽车」，并自由调整房间在平面图上的网格位置与大小。

### 2.5 周期订阅资产追踪
- 纳管 iCloud、ChatGPT Plus、宽带、流媒体年卡等周期订阅。
- 自动折算**月均支出**与**年化支出**。
- 支持到期前 1~3 天发送系统通知栏扣费预警。

### 2.6 物品在役/退役与待办归置
- 物品闲置或损坏时，点击「更多 ➔ 物品退役与待办归置」。
- 选择归置方案：`📦 挂闲鱼代售` / `📱 挂转转二手` / `🎁 赠送亲友` / `🗄️ 封箱入库` / `♻️ 环保回收` / `🗑️ 报废`。
- 记录出掉回血金额，回血收益自动计入报表统计。

### 2.7 生活流与统计报表
- **生活流**：按时间倒序清晰呈现每一笔入库、出库、退役流转流水。
- **报表中心**：展示 Top 5 品牌资产排行、分类占比环形色条、各年度月度收支与折旧明细。

### 2.8 触感震动与深浅外观主题
- **触感震动反馈**：所有按键、药丸标签、微动效均伴随物理线性微震（可在「我的 ➔ 更多设置」中一键开关）。
- **深浅外观主题**：支持「📱 跟随系统」、「☀️ 浅色明亮」与「🌙 深色暗黑」。

### 2.9 数据备份恢复与 CSV 导出
- **Excel 兼容导出**：一键生成带 UTF-8 BOM 的「资产总表 (CSV)」与「流水明细 (CSV)」，直接拉起系统分享发至微信/电脑。
- **JSON 备份恢复**：一键生成完整数据 JSON 备份包至剪贴板，换机时一键粘贴恢复。

## 3. 调试与模拟器运行指南

### 3.1 命令行启动模拟器
```bash
# 启动 DiaperPhone Pixel 6 模拟器
emulator -avd DiaperPhone
```

### 3.2 常用 ADB 指令
```bash
# 查看已连接设备
adb devices

# 安装与更新 APK
adb install -r app/build/outputs/apk/release/app-release.apk

# 启动应用
adb shell am start -n com.kfaino.diapertracker/.MainActivity

# 查看应用日志
adb logcat -s Collecter DiaperTracker
```
