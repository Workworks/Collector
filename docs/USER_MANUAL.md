## 1. 资产记账与双模态全景看板

### 1.1 双模态资产池切换
- **物品资产池**：纳管个人拥有的实体物品、数码家电、家具服饰、日用消耗品等。
- **订阅资产池**：纳管软件订阅（ChatGPT Plus、iCloud、网易云、Netflix）、网络宽带、健身房年卡等周期性服务。
- 顶部药丸切换器可一秒在两者之间无缝切换。

### 1.2 财务指标透视
- **总资产估值**：在库在役物品的净值总和。
- **日均使用消费成本（元/天）**：自动根据每件折旧资产的购入天数与残值进行加权平摊。
- **多维筛选排序**：支持按「在役/退役状态」、「拥有天数」、「总价估值」、「日均成本」及「分类」即时排序筛选。

## 2. 4 维物品管理分类体系与折旧成本算法

在记一笔或编辑物品时，可为物品指定 4 维管理类型：

| 管理分类 | 典型物品 | 核心特征与算法 | 列表视觉展示 |
| :--- | :--- | :--- | :--- |
| 📉 **折旧资产** | 笔记本电脑、手机、微单相机、智能手表 | 动态计算：`日均成本 = (原价 - 二手估值) / 拥有天数` | 显示拥有天数与 `¥X.XX/天` 标签 |
| ⏳ **保质期物品** | 药品、护肤美妆、食品特产、茶叶咖啡 | 绑定生产日期与到期日期，支持快捷标签（30天/半年/1年/2年/3年） | 临期倒计时预警（绿/黄/红状态色） |
| 🛋️ **长期耐用品** | 实木家具、乐器、纪念品、黄金首饰 | 仅记录拥有天数与购入原价，不平摊每日损耗 | 显示拥有天数与原价 |
| 📦 **日常消耗品** | 纸尿裤、卷纸、咖啡豆、打印纸 | 关注库存数量与单件成本，支持出库消耗 | 显示库存件数与单价 |

### 2.1 📅 现代化全景日期选择器 (跨年代与快捷标签)
- **跨年代网格直达**：点击顶栏 `[ 2024 年 ▼ ]` 展开 1980~2035 年份网格，点击目标年份即刻完成十年跨越；点击 `[ 8 月 ▼ ]` 展开 1~12 月份网格秒速直达。
- **常用时间快捷标签**：顶栏提供 `今天`、`昨天`、`1个月前`、`1年前`、`2年前`、`3年前`、`5年前` 标签，一键点选完成回溯。
- **相对天数直观感知**：实时计算并显示 `距今 1478 天前` 或 `未来 45 天后`。
- **触感微动效**：每个日期格子与年份选项均支持按压微缩放动效与线性马达触感震动。

## 3. 实物照片与购买发票/保修卡凭证管理 (私有沙盒)

### 3.1 双插槽设计
- **📷 实物照片**：点击添加实物拍摄照片，列表卡片自动以圆角实物图作为封面。
- **🧾 发票/保修卡**：点击上传电子发票、购买订单截图或保修卡照片，卡片右下角点亮「🧾 凭证」徽章。

### 3.2 100% 离线隐私沙盒与性能优化
- **安全沙盒**：所有图片压缩保存至应用私有沙盒（`context.filesDir/item_vault/`），绝不上传云端。
- **EXIF 角度纠偏**：自动检测相机传感器旋转角度并纠正方向。
- **LRU 缓存与动态采样**：长列表使用 120x120 采样，大图预览使用 1200x1200 采样，百张照片长列表滑动绝不 OOM。
- **全屏沉浸查看器**：点击缩略图或发票徽章唤起全屏查看器，支持多指缩放与调用系统分享。

## 4. 空间平面图、寻物地图与双向穿梭定位

### 4.1 多空间与房间网格配置
- 支持自由创建多个空间（`🏠 自己的家`、`🏡 父母家`、`🏢 办公室`、`🚗 汽车后备箱`）；
- 支持为空间添加房间（`主卧`、`书房`、`阳台`、`衣帽间`），自由配置房间在平面图上的网格坐标、大小、Emoji 图标与主题色。

### 4.2 双向穿梭寻物
1. **由物找空间（一键定位）**：
   - 在首页卡片点击「📍 主卧 · 衣柜」等位置标签；
   - 平面图自动弹出，空间自动切换，对应房间高亮，物品打点处呈现**金色呼吸脉冲光晕 (Pulsing Pin)**。
2. **由空间看物品（资产抽屉）**：
   - 在平面图点击任意房间；
   - 底部流畅展开该房间内的**全部在库物品抽屉**，点击任意条目可直接查看与编辑。

## 5. 收纳箱专属二维码标签生成与智能扫一扫

### 5.1 生成收纳箱二维码标签
- 在平面图点击任意房间/收纳箱，在资产抽屉中点击【🏷️ 生成二维码标签】；
- 弹出高清晰度标签卡片，展示所属空间、房间名称、物品种类件数与 Collecter 标识；
- 点击【💾 保存到相册】或【📤 一键分享打印】，贴在收纳箱体上。

### 5.2 智能扫一扫 (100% 离线识别)
- 点击首页顶栏【📷 扫一扫】：
  - **扫描收纳箱二维码**：秒级识别 `collecter://room?...` 协议，直接打开平面图高亮并滑出箱内所有物品；
  - **扫描商品条形码**（EAN-13 等）：自动匹配已有物品直接打开编辑，或自动填入条码信息快速记账。

## 17. 📦 简易库存模式 (Simplified Inventory Mode)

- **模式切换**：前往【我的 ➔ 更多设置 ➔ 📦 简易库存模式】开启/关闭。
- **极简化体验**：

  - 底部导航精简为 3 栏：`📦 仓库库存`、`📋 出入流水`、`⚙️ 系统设置`；

- **数据 100% 共享**：简易模式与普通全功能模式共用同一套底层本地数据库，随时无缝自由切换，数据绝不割裂、绝不丢失。

## 18. 🐧🍎 跨平台桌面端 (Linux & macOS)

- **支持平台**：
  - **Linux**（Ubuntu / Debian / Arch / Fedora 等，提供 `collecter-desktop-linux-v2.8.0.tar.gz` 与 `collecter.desktop` 快捷方式）；
  - **macOS**（Apple Silicon M系列 / Intel，提供 `collecter-desktop-macos-v2.8.0.zip` 与 `launch_macos.command` 一键直启脚本）；
  - **通用独立跨平台包**：`Collecter-Desktop-v2.8.0-Universal.jar`（需 Java 17+）。
- **运行环境**：
  - 安装 JRE / JDK 17 或更高版本：
    - macOS: `brew install openjdk@17`
    - Ubuntu/Debian: `sudo apt install openjdk-17-jre`
- **桌面专属快捷键**：
  - `⌘+N` / `Ctrl+N`：极速呼出记账与出入库窗口；
  - `⌘+S` / `Ctrl+S`：一键触发 WebDAV 云同步；
  - 宽屏大盘：左侧模块导航、居中库存流水表格与可视化数据报表。
- **与手机端数据无缝互通**：
  - 桌面端数据存储于 `~/.collector/collector_data.json`；
  - 在桌面端【系统设置 ➔ WebDAV 配置】中填入与手机端相同的网盘账号与密码，随时一键上传/下载，多端数据完美同态一致！
