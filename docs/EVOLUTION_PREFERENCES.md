# 🧭 Collecter 系统演化偏好与决策总纲 (User Evolution Preferences & History)

> **核心铁律**：每次用户提到“演化”、“演化建议”或“系统进化”时，**必须首先读取并严格遵循本文件**中记载的用户核心喜好、审美偏好与被否决的负向清单，绝不重复提出已被否决的乏味方向！

---

## 💎 用户核心喜好与认可方向 (Liked & Appreciated)

1. **数字资产与实体资产双轨融合（高度认可 🌟🌟🌟🌟🌟）**
   - **用户原话**：“我喜欢纬度4，相册电子的东西也能作为资产保存。”
   - **代表成果**：v3.6.0 数字相册与电子资产专属展厅（相册集/软件Key/域名/数字文档/网盘备份状态）。
2. **物品生活时光胶囊与高质感生活回忆画册（高度认可 🌟🌟🌟🌟🌟）**
   - 物品不仅仅是冷冰冰的财务数字，更是生活的见证；
   - 记录生活故事、陪伴天数、日均成本、真香评分（1~5星），原生 Canvas 离线绘制 1080P 高清拍立得/杂志风生活画册长图海报。
3. **实物外借流转与智能借还追踪（高度认可 🌟🌟🌟🌟🌟）**
   - **代表成果**：v3.7.0 实物外借流转中心、借用人档案、归还倒计时、1080P 电子借条凭证与微信体面催还海报。
4. **极简主义与克制设计**
   - 支持「简易模式」一键隐藏非核心功能，聚焦极简仓库库存；
   - 二级工具箱支持优雅折叠（默认不冗余展示），分类清晰直观。
5. **极高质感的视觉体验与动效**
   - 26dp 双层圆角微光卡片、按压缩放弹簧动效、呼吸微光光晕、原生 Canvas 1080P 超清海报离线生成（相册直接分享）。
6. **热更新与游戏化秒级分发**
   - 支持类游戏式的增量动态热补丁（免重新安装升级）。
7. **交付与发布铁律**
   - **用户原话**：“以后完成任务后上传GithubRelease”、“并且所有的功能点都要有跟手的步骤教程，中途可以退出教程”。
   - 每次任务完成后必须执行全平台编译测试、打包 5 大分发包并发布 GitHub Release，并同步更新全景教学与跟手演练。

## 🚫 用户明确否决/不喜欢的负向清单 (Disliked & Rejected)

在后续演化中，**严禁再次推荐以下类型**：

| 被否决方向 | 典型特征与被否决原因 |
| :--- | :--- |
| ❌ **复杂的外部智能家居/IoT 协议接入** | 用户原话：“自动化生态目前不用考虑，重新演化”。脱离纯净离线资产管理主线，引入外部依赖与网络负担。 |
| ❌ **枯燥繁琐的纯售后/工单/电话簿** | 传统的售后保修卡包、网点电话拨号、工单流转等，用户多次明确表示“这些都不行”、“这些方向我不满意”。 |
| ❌ **重度复杂的 3D CAD/网格化空间建模** | 繁琐的 3D 模型与空间渲染，过于冗余且不实用。 |
| ❌ **底层硬件极客体检** | 如 OTG 读写测速、SMART 硬盘体检、电池循环曲线等，脱离生活与日常资产管理场景。 |

## 📜 历史演化版本记录 (Evolution Milestones)

- **v3.1.0 ~ v3.4.0**：空间平面图、扫码与 NFC 寻物、多账本独立空间、发票凭证沙盒、动态折旧、局域网 Web 控制台、实物大盘点。
- **v3.5.0 ~ v3.5.3**：类游戏秒级动态热更新、全局 UI 高定微光重构、全新品牌图标、23+ 项全景教程与跟手演练系统。
- **v3.6.0**：**【维度 4 落地】** 物品时光胶囊与生活画册回忆录、数字相册与电子资产专属展厅、1080P 拍立得画册海报生成器。
- **v3.7.0**：**【维度 2 落地】** 实物外借流转追踪与智能借还管理系统、1080P 电子借条凭证与微信温馨催还海报引擎。

## 🎯 未来的演化决策原则 (Decision Principles)

1. **紧扣生活质感、情感与实用价值**：围绕个人装备、穿搭、旅行出行、珍藏展品、数字文化资产等有温度的场景展开。
2. **纯原生离线与高颜值海报输出**：坚持端侧 100% 离线、无需注册、Canvas 超清水印级海报一键导出相册分享。
3. **保持操作极简与交互愉悦**：轻量易上手，随时可折叠、可穿透、可退出。
