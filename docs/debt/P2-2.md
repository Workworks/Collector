# P2-2　抽象 8 个雷同的收纳馆弹窗

**状态**：⬜ 待办　**优先级**：P2　**需用户同意后再动手**：是（结构性重构）

## 现状

`FoodVaultDialog`、`HonorVaultDialog`、`FamilyVaultDialog`、`VoucherVaultDialog`、
`FamilyMedicineDialog`、`DigitalAssetManagerDialog`、`LendingManagerDialog`、`LifeCapsuleDialog`
结构高度雷同（成员分类 Tab + 列表 + 登记表单 + 到期预警 + 导出），单馆平均约 450 行。

改一处配色或交互要动 8 个文件。第 9 个馆会让这个成本再涨一档。

## 做法

抽 `BaseVaultDialog`，把「分类 Tab / 列表渲染 / 登记表单 / 临期预警 / 空态」做成模板方法，
各馆只提供差异化配置。

⚠️ 动手前必须先向用户说明影响面并取得同意。

## 验收标准

- [ ] 8 个馆的行为与重构前完全一致（逐个手动走一遍主流程）
- [ ] 新增第 9 个馆时，新增代码量显著低于 450 行
