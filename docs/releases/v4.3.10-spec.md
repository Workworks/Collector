# v4.3.10 发布与后续验证 Spec

日期：2026-09-05。

## 目标

将 Stage 463–468 已完成的受限网络下载兜底、低门槛产品体验、家庭协作联调、搜索找回卡和统一弹框 UI 作为 v4.3.10 正式交付，并从发布完成日起启动 14 天低门槛使用验证。

## 边界与不变量

- Android 版本由 4.3.9 / 46 提升为 4.3.10 / 47；Desktop 同步为 4.3.10，因为本批次包含桌面家庭配对入口和跨端联调支持。
- 保持 `applicationId`、namespace、用户数据键和签名证书不变；不得通过卸载绕过升级失败。
- 更新下载顺序保持 GitHub API、GitHub 官方资源、摘要校验镜像；任何来源均须通过 GitHub Release 声明的大小和 SHA-256。
- Windows Native 只发布未签名便携包；没有受信代码签名证书和第二台干净 Windows 时，不宣称安装器验收完成。
- 14 天验证以本地记录和用户主动反馈为数据源，不引入远程行为采集。

## 工作包

- WP-01：版本、README、CHANGELOG、任务账本和发布说明同步。
- WP-02：Android Release、Desktop JAR 与 Windows Native ZIP 构建；运行全量单测、自检、APK 验签。
- WP-03：从 GitHub v4.3.9 APK 覆盖升级到 v4.3.10，确认包名、版本、数据探针和冷启动。
- WP-04：创建 Git 提交、注释 tag 和 GitHub Release，上传三项附件并回下载核对摘要。
- WP-05：验证最新 Release API、APK 官方/API/镜像下载候选及错误反馈，记录物理网络边界。
- WP-06：启动 14 天低门槛使用验证，按天记录录入耗时、找回成功、待整理积压和提醒处理。
