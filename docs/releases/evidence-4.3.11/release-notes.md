Collecter v4.3.11 把已经完成的账单模块正式带到 Android 用户版本。

## 本版新增

- 底部“账单”入口，按月查看已入账支出、收入和待入账金额。
- 手动记账只需项目和金额，其余字段均可选。
- 快速文本记账：粘贴多行手账，预览后一次保存。
- 兼容日期头、USD、未入账、订阅周期、油耗和里程备注。
- 账单纳入完整备份、WebDAV 和跨端数据保真。

## 使用示例

```text
@2026-09-27
支出 52 餐饮 小母鸡 #已入账 ; 原价45+配送7
支出 28.82 采购 打包盒 #未入账
支出 20USD 订阅 ChatGPT #每月 ; 自动续费
```

## 平台说明

- Android 提供完整账单录入和管理界面。
- Desktop 4.3.11 可无损保留并备份账单集合，但本版暂不提供账单编辑界面。
- Android 包名与原签名保持不变，可从 v4.3.10 直接覆盖升级。
