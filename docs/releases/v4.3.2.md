# Collecter v4.3.2 发布说明 (Release Notes)

> **发布日期**：2026-08-29
> **版本号**：`v4.3.2` (`versionCode: 39`)
> **核心主题**：桌面单机版 Native WebView2 架构重构 · 局域网 P2P 双机自发现增量对撞 · 灵感想法舱与智能剪藏知识库

---

## 🌟 重大更新亮点

### 1. 🖥️ 桌面单机版架构重构 (Native WebView2 + `%LOCALAPPDATA%` 隔离)
- **C++ 原生宿主窗口 (`CollecterWindow.cpp`)**：支持 Windows 单实例互斥防重开、系统托盘常驻与右键控制、启动自探测平滑过渡；
- **独立数据目录**：Windows 本地数据隔离存放至 `%LOCALAPPDATA%\CollecterStandalone\data`，软件卸载/覆盖安装不丢数据；
- **全量 12 馆数据模型对齐**：桌面端持久化全量覆盖卡券、药箱、食材、绿植、宠物、藏书、茶窖等全部 12 大收纳馆。

### 2. 🌐 局域网 UDP 秒级自发现与双机 P2P 增量对撞合并
- **UDP 广播设备自发现 (Port 8849)**：同一 Wi-Fi 下自动广播并秒级探测在线手机端与桌面端，免去手动查找配置 IP 端口的繁琐步骤；
- **P2P 增量对撞合并核心引擎**：
  - 基于实物 UUID 唯一寻址；
  - 采用 Last-Write-Wins 时间戳智能冲突仲裁；
  - 12 馆全量物资无损互通，合并分类与房屋空间集合；
  - 结构化 `MergeReport` 详细汇报新增、更新、保留项。

### 3. 🧠 全态资产纳管：灵感想法舱与智能剪藏知识库
- **💡 闪念灵感舱 (`IdeaVaultDialog`)**：
  - 0.5 秒极速记录生活顿悟、灵感便签、读书心得与随手待办；
  - 支持多色卡片流、置顶管理、标签过滤与跨维实物关联；
- **📰 智能剪藏知识库 (`ClippingVaultDialog`)**：
  - 网页长文与截图快照离线归档，纯净 Markdown 沉浸式阅读器；
  - 截图 OCR 全文索引提取，本地私有媒体沙盒防失效；
- **🔍 全维极速穿透检索**：
  - 全局搜索框一键毫秒级贯通「实物资产 + 12大专业馆 + 灵感想法 + 剪藏文章/截图 OCR」。
