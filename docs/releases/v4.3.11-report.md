## 用户可见变化

- 底部第三核心入口调整为“账单”，支持按月查看支出、收入和待入账金额。
- 支持只填项目和金额的手动记账，并可编辑、删除或确认待入账。
- 支持粘贴多行手账文本，解析预览后批量保存；未识别行不会静默生成记录。
- 兼容 `项目: 20USD`、`采购+40（未入账）`、油耗/里程等既有手账写法。
- 账单进入完整备份、WebDAV 和跨端保真链路。

## 验收边界

- API 34 模拟器原签名覆盖升级和账单设备测试通过；没有实体手机，蜂窝网络、厂商后台、真实输入法组合和两台物理设备配对继续标记 `BLOCKED`。
- Native Host 在本机 smoke 通过；没有第二台干净 Windows 和受信代码签名证书，因此便携包保持未签名，不宣称 SmartScreen 或干净机验收完成。
- 当前只有临时 Quick Tunnel；固定 WebDAV 域名、凭据/业务库加密迁移和持久上传队列仍等待外部前置。
