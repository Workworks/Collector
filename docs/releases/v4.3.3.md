# Collecter Android v4.3.3

> 发布候选，尚未公开发布。缺少旧版签名，详见 [验收报告](v4.3.3-report.md)。

本次仅发布 Android APK，versionCode 40。Android 包名保持 com.kfaino.diapertracker。Windows 原生包尚未完成编译和安装升级验收，本次不提供，也不更新桌面版本号。

## 更新
- 完整 JSON 备份覆盖专业馆、想法、剪藏、收集箱、关系、提醒与附件；恢复前校验和预览，失败保护原数据。
- 局域网互传增加访问密钥与来源校验；共享同步契约保留未知字段、删除标记与冲突副本。
- 统一文字、链接和照片收集入口，保留原件、本地 OCR 和重试；支持双向关联与跨类型找回。
- 提醒支持完成、延后、关闭和按周期去重。
- 修复 WebDAV 恢复取错返回字段、清空记录同步复活，以及订阅周期双端转换问题。

## 升级与限制
升级前先导出备份，保留原 APK；不要通过卸载旧版解决安装问题。新版数据不建议直接用旧版程序编辑。

局域网使用 HTTP，仅用于可信网络；未完成真实多设备全业务字段互通、长期通知调度、损坏图片重试和第三方分享兼容矩阵验收。整份 JSON/附件备份仍有内存开销，大数据量操作可能卡顿。本次不声称全部 Stage 453 验收已完成。

本次不发布动态 DEX/热更新 ZIP，请使用完整 APK 更新。验证与签名记录见 v4.3.3 发布验收报告。
