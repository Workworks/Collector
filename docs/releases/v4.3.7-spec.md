# v4.3.7 正式发布规格

日期：2026-09-01。用户明确要求发布 4.3.7。

## 目标与边界

以已整合并推送的 Stage 457 main 为唯一候选，将 Android 从 4.3.6 / 43 升至 4.3.7 / 44，桌面 JAR 同步为 4.3.7。applicationId、存储键与原发布签名保持不变。创建 Git tag 和正式 GitHub Release，上传 Android APK 与桌面 Universal JAR；不发布未配置受信公钥的动态 DEX 补丁，不把 JVM JAR描述为 Native 安装器。

## 完成标准

| AC | 完成条件 | 验证 |
| --- | --- | --- |
| AC-01 | 候选仅含预期版本/说明变更，远端 main 无新分叉 | fetch、diff、版本三处一致 |
| AC-02 | 完整门禁通过，DEX/ZIP/WebDAV/迁移回归不缺失 | 三端测试、assembleRelease、selfcheck |
| AC-03 | APK 包名、44/4.3.7 与原签名准确 | aapt/apksigner/Verify-AndroidRelease |

| AC-05 | 发布提交、tag、Release 及两个附件一致 | push、gh release、下载哈希、ls-remote |

物理设备本轮不可用，模拟器升级为发布门禁的当前设备证据；报告必须明确这一限制。
