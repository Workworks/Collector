# Collecter v4.3.12

本版修复应用内更新在首次安装授权后中断的问题。

## 修复

- 首次点击应用内安装且尚未开启“允许安装未知应用”时，授权返回后自动继续进入 Android 系统安装确认页。
- 授权返回后重新核对安装请求时效、应用私有目录边界、APK 大小和 SHA-256，校验不通过时拒绝安装。
- 用户未授权时给出明确提示，可回到更新入口重试。

## 升级说明

- Android 包名、数据目录和原发布签名保持不变，支持从 v4.3.11 覆盖升级。
- Android 仍会显示系统安装确认页，不执行静默安装。
- 如果当前旧版本在授权后仍停留原页面，请返回“检查与智能升级”再次点击安装；权限已经开启时可正常进入安装器。也可使用系统浏览器下载本 Release 的 APK。
- Desktop 4.3.12 仅同步版本标识，功能与 v4.3.11 相同。
