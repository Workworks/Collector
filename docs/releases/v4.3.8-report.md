# v4.3.8 发布验收报告

日期：2026-09-01。该版本修复移动端应用内下载出现 `Chain Validation failed` 的问题，旧版基准为 GitHub Release v4.3.7 的真实 APK。

## 根因与修复

- `mirror.ghproxy.com` TLS 握手失败，`ghproxy.net` 证书过期；旧实现最终只展示最后一个候选的异常，掩盖了各通道的真实结果。
- `ghfast.top` 在 Android 14 联网测试中返回 HTTP 403，因此也从正式候选中移除。
- 全量 APK 与热补丁检查统一只使用 GitHub 官方源。失败弹窗显示具体原因，提示检查自动日期时间，并允许交给系统浏览器打开官方下载地址。
- APK 缓存、静默预下载与前台下载统一校验 GitHub asset 声明的大小及 SHA-256；不匹配时删除文件并拒绝安装。
- 没有关闭 TLS 校验、信任任意证书或放宽 Android 安装签名。

## 已知边界

- 联网与覆盖升级验证使用 Android API 34 模拟器，没有物理设备。
- 若设备系统时间错误、系统根证书过旧，GitHub 官方 TLS 仍可能失败；应用会明确提示并提供浏览器入口。
- GitHub 在特定网络不可达时不再尝试第三方代理，避免证书、访问策略和内容替换风险。
- Desktop 交付物仍为 Java 17 Universal JAR，不是 Windows Native 安装器。
