# Collecter v4.3.10

这个版本重点降低首次使用门槛，并改善受限网络下的更新体验。

## 新增与改进

- 首次打开只需选择“拍照收纳、记下物品、粘贴链接、以后再整理”，无需预先学习分类和账本。
- 快速录入只要求名称，自动填写时间、通用分类和“未整理”位置。
- 默认底栏聚焦“资产、收集箱、提醒、我的”，地图、多账本和专业馆收进“更多功能”。
- 收集箱支持文字、链接、图片和扫码，新增五种家庭场景模板及可跳过的智能默认建议。
- 首页显示今日事项、最近找到的物品、整理进度和有效提醒反馈。
- 统一搜索结果新增找回卡，可直接查看位置、备注、照片、票据与关联资料。
- 全部 Android 弹框统一圆角、排版、遮罩和短促淡入缩放动画。

## 更新与安全

- 应用内下载依次尝试 GitHub API、GitHub 官方资源和摘要校验镜像，失败时显示具体来源。
- 不论下载来源，APK 都必须通过 GitHub Release 声明的文件大小和 SHA-256，校验失败不会进入安装流程。
- 保持 Android 包名和原签名不变，支持从 v4.3.9 覆盖升级并保留数据。

## Desktop

- 增加家庭配对内容输出与双端联调支持。
- 提供 Universal JAR 和 Windows Native WebView2 便携包。Windows 便携包尚未使用商业代码签名证书，请仅从本 Release 下载并核对摘要。

完整验收记录见 `docs/releases/v4.3.10-report.md`。
