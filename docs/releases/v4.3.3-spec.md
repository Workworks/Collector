# Android v4.3.3 发布 Spec

状态：BLOCKED（缺原发布签名）。用户于 2026-08-30 明确要求发布新版本。

目标：将当前可靠性与收集功能作为 Android v4.3.3（versionCode 40）发布到已有 Workworks/Collector GitHub Releases，附精确版本 APK、校验和及已知限制。

边界：保留 Android 包名与原有签名；不发布未编译验证的 Native Windows 包，不把 desktop 4.3.2 升号伪装交付，不生成不具备验签条件的热更新包。保留既有工作树全部内容，不上传凭据、本地构建缓存或 OBJ。版本自检三端一致项如因 Android 独立发布失败，完整记录而不修改 selfcheck。

验证与完成标准：
- AC-R1：查询远端确认版本不重复，Android versionCode 递增；README 标明 Android 与桌面范围。
- AC-R2：新旧 APK applicationId 与签名证书一致；不一致则禁止公开可覆盖升级版本，保留本地产物并报告需要原签名。
- AC-R3：Android/共享/桌面测试与 Release 构建通过，原始 selfcheck 输出留存；跨端版本分离仅作为明确不适用项说明。
- AC-R4：发布源码提交与 APK 对应，排除私密与构建产物；Release tag 指向该提交，上传校验和与发布说明。
- AC-R5：远端读取确认非草稿发布、附件完整、下载 SHA-256 一致；旧版本不覆盖、不删除。

工作区：通过仅单次 git -c safe.directory=F:/LANShare/AgentWorkSpace/Collector 访问用户明确指定仓库，不修改全局信任。远端 main 与本地 HEAD 在发布开始时一致，保留并审查本地未提交实现。

验收回填：AC-R1 PASS；AC-R2 BLOCKED（签名不同）；AC-R3 构建/69 项测试通过，自检三端版本项按独立发版真实记录未通过；AC-R4/R5 未执行，禁止带已知签名冲突公开发布。完整证据见 [发布验收报告](v4.3.3-report.md)。
