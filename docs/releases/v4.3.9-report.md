## 客观边界

- `BLOCKED`：当前只有 API 34 模拟器，没有物理 Android 设备，因此物理设备认证、独立两设备网络、厂商后台限制和真实移动网络长期测试不能标 PASS。
- `BLOCKED`：只有 Quick Tunnel，没有受管 Cloudflare Tunnel、固定域名或域名控制权；公网协议通过不等于固定生产入口。
- `BLOCKED`：没有物理设备凭据恢复环境，因此没有启用业务库/WebDAV 凭据的破坏性加密迁移；只交付后台重锁。持久上传队列也未静默启用，以免在缺少凭据恢复与冲突人工处理 UI 时造成错误覆盖。
- Windows Native 是未签名便携包，不冒充已签名安装器；已验证本机启动/退出，未在第二台干净 Windows 主机验证。
