## 🌟 核心特性一览

### 1. 🧠 全态资产纳管 & 数字大脑 (Life Assets & Second Brain)
- 📊 **三维资产独立录入与看板**：精准分流「实物资产」、「周期会员订阅」与「数字相册/电子资产」三大形态，彻底告别冗余参数干扰。
- 💡 **闪念灵感与想法收纳舱**：0.5 秒极速记录生活顿悟、灵感便签与读书心得，多色主题卡片流、置顶管理与实体资产关联。
- 📰 **智能剪藏与文章知识库**：网页/截图全文离线 Markdown 沉浸式阅读、OCR 提取全文索引、本地媒体沙盒存档。
- 🔍 **全维极速穿透检索**：一键毫秒级贯通「实物资产 + 12大专业馆 + 灵感想法 + 剪藏文章/截图 OCR」。
- 💰 **日均折旧成本精算**：实时计算每一件数码/家具/日用资产的**拥有天数、日均使用成本（元/天）**与二手回血折旧曲线。

### 2. 🏛️ 第一性原理 12 大全维度收纳展馆与时效生命线
- 🎟️ **时效权益与卡券票据收纳馆**：优惠券、代金券、洗车/健身次卡、会员每月专属权益统一归拢，3天临期强提醒，次卡一键扣减打卡。
- 🪪 **家庭多成员证照安全夹与商业保单契约**：全家身份证、护照、户口本、结婚证、房产证、车险/人身保单与重要合同加密归档，证号一秒脱敏复制，Canvas 防盗流水印导出与到期换证/续保预警。
- 💊 **家庭智能健康药箱**：对症速查（发热/感冒/肠胃/外伤/过敏）、用法用量备忘、开封倒计时打卡、过期药品红牌严禁服用强预警。
- 🥦 **冰箱冷冻与食材生鲜鲜度库**：冷冻/冷藏/干货调味四温区管理，开封保鲜倒计时，3天临期琥珀色预警与「今晚清库存」一键筛选。
- 🏆 **全家成长履历与荣誉考级勋章馆**：全家学历、职业资格、考级认证与比赛获奖归档，年审换证预警，1080P 人生高光足迹长卷导出。
- 👗 **换季衣橱与四季穿搭舱**：四季胶囊衣橱分舱、真空压缩袋封存/解封入柜、穿着打卡、次均穿戴成本精算与 180 天沉睡未穿预警。
- 🚨 **家庭应急防灾与生命线舱**：地震/火灾/车载/暴雨四大避难专包、黄金动线存放定位、物资保质期/滤毒罐生命线追踪与季度点检打卡。
- 🔧 **家庭工具五金与设备维保配件舱**：电动/手工工具分类、螺丝钻头搭配速查、净水新风等设备耗材周期维保排期与一键打卡。
- 🪴 **家庭绿植花卉与水肥养护舱**：光照习性档案（全日照/散光/耐阴）、水肥日历周期排期计算、临期/逾期智能预警与一键浇水/施肥打卡。
- 🐾 **家庭萌宠生活与疫苗驱虫舱**：物种档案、体重与电子芯片号脱敏速查、驱虫与疫苗排期倒计时、主粮存放定位与一键打卡。
- 📚 **家庭书房藏书与阅读收纳舱**：书架物理格子定位、阅读进度百分比追踪、实体书外借流转与精读感悟评分。
- 🍷 **家庭茶窖与名酿适饮时效舱**：名茶名酒存藏定位、陈化年份精算、最佳适饮熟成峰值年提醒与开瓶保鲜打卡。
- 🏛️ **全维度收纳大厅与生命线总控看板**：12 大专业收纳馆全局聚合、全景临期失效红绿灯雷达与 100 分制收纳健康度评分。

### 3. 🌐 局域网 P2P 双机自发现与桌面端生态
- 📡 **UDP 广播秒级设备自发现 (Port 8849)**：同一 Wi-Fi 下自动探测在线手机端与桌面端，免手动配置 IP。
- 🔄 **P2P 增量对撞合并引擎**：唯一 ID 寻址、Last-Write-Wins 时间戳冲突仲裁与 12 馆物资全量无损互通。
- 🖥️ **桌面单机版架构 (Windows Standalone)**：Native C++ WebView2 宿主、`%LOCALAPPDATA%` 独立数据隔离、常驻 8848 嵌入式 Web 控制台与系统托盘。

### 4. 🗺️ 空间可视化与微观收纳
- 🗺️ **空间平面图与寻物高亮穿梭**：可视化家庭空间多房间 Canvas 平面图，支持**由物找空间（呼吸脉冲高亮打点）**与**由空间看物品（房间在库资产抽屉）**双向穿梭。
- 🏷️ **收纳箱专属二维码与智能扫码**：一键生成箱盒专属二维码标签（支持保存与打印），扫一扫秒查箱内清单，扫描商品条码极速匹配入库。
- 📶 **智能互联（NFC / 蓝牙热敏打印 / 局域网）**：支持 NFC 碰一碰快速找物、蓝牙热敏标签机一键直印箱盒便签、局域网 Web 大屏免装互传。

### 5. 🤖 智能输入与数据安全
- 🤖 **AI 多模态智能免录**：拍照购物小票/发票/包装盒 OCR 识别与字段提取，自然语言一句话记账智能拆解。
- 📋 **电商订单剪贴板无感桥接**：侦测复制的淘宝、京东、拼多多商品分享文本，自动弹出卡片一键结构化快速入库。
- 🔐 **生物识别指纹/面容隐私锁**：系统原生指纹/面容锁屏验证，严密守护个人与家庭资产隐私。
- ☁️ **WebDAV 私有云安全同步**：支持坚果云、Nextcloud、群晖 Synology 等标准网盘，一键备份与多端还原。
- 📊 **多格式数据备份与导出**：一键生成带 UTF-8 BOM 的 **Excel 兼容 CSV 资产总表与流水表**，完整 JSON 本地备份。
- 🚀 **智能统一在线更新**：官方源直连优先，免重装热补丁秒级生效与全量 APK 智能回退。

```powershell
.\gradlew.bat :app:testReleaseUnitTest

# 安装到连接的设备/模拟器
adb install -r app/build/outputs/apk/release/app-release.apk
```
