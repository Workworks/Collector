## 🌟 核心特性一览

### 1. 📦 全生命周期资产纳管 & 日均成本精算
- 📊 **三维资产独立录入与看板**：精准分流「实物资产」、「周期会员订阅」与「数字相册/电子资产」三大形态，彻底告别冗余参数干扰。
- 💰 **日均折旧成本精算**：实时计算每一件数码/家具/日用资产的**拥有天数、日均使用成本（元/天）**与二手回血折旧曲线。
- 📦 **物品在役/退役与待办归置**：支持挂闲鱼代售、转转二手、赠送亲友、封箱收藏与环保报废，完整追踪二手回血收益。
- 📸 **实物照片与发票/凭证私有沙盒**：100% 本地沙盒私有存储，自动纠偏压缩，沉浸式大图浏览与发票凭证存档。

### 2. 🏛️ 第一性原理全维度收纳展馆
- 🎟️ **时效权益与卡券票据收纳馆**：优惠券、代金券、洗车/健身次卡、会员每月专属权益统一归拢，3天临期强提醒，次卡一键扣减打卡。
- 🪪 **家庭多成员证照安全夹与商业保单契约**：全家身份证、护照、户口本、结婚证、房产证、车险/人身保单与重要合同加密归档，证号一秒脱敏复制，Canvas 防盗流水印导出与到期换证/续保预警。
- 💊 **家庭智能健康药箱**：对症速查（发热/感冒/肠胃/外伤/过敏）、用法用量备忘、开封倒计时打卡、过期药品红牌严禁服用强预警。
- 🥦 **冰箱冷冻与食材生鲜鲜度库**：冷冻/冷藏/干货调味四温区管理，开封保鲜倒计时，3天临期琥珀色预警与「今晚清库存」一键筛选。
- 🏆 **全家成长履历与荣誉考级勋章馆**：全家学历、职业资格、考级认证与比赛获奖归档，年审换证预警，1080P 人生高光足迹长卷导出。
- 🎒 **场景装备套装与旅行出差装箱舱**：内置商务出差、露营、亲子出行预设，支持【🛫 出发装箱】与【🏨 离店返程清点】双向核对，1080P 出行清单海报一键生成。
- 🎞️ **物品生活时光胶囊与高质感画册**：记录物品陪伴故事、高光时刻与真香评分，Canvas 绘制 1080P 高清拍立得杂志风长图海报。
- 📤 **实物外借流转与智能催还凭证**：实物借出登记、还期倒计时、高清电子借条交接单与微信温馨催还图文海报。
- 📷 **数字相册与电子资产专属展厅**：照片回忆集、正版软件授权 Key、域名与资料包集中归档，3-2-1 备份健康度追踪与 Key 一键复制。

### 3. 🗺️ 空间可视化与微观收纳
- 🗺️ **空间平面图与寻物高亮穿梭**：可视化家庭空间多房间 Canvas 平面图，支持**由物找空间（呼吸脉冲高亮打点）**与**由空间看物品（房间在库资产抽屉）**双向穿梭。
- 🏷️ **收纳箱专属二维码与智能扫码**：一键生成箱盒专属二维码标签（支持保存与打印），扫一扫秒查箱内清单，扫描商品条码极速匹配入库。
- 📶 **智能互联（NFC / 蓝牙热敏打印 / 局域网）**：支持 NFC 碰一碰快速找物、蓝牙热敏标签机一键直印箱盒便签、局域网 Web 大屏免装互传。

### 4. 🤖 智能输入与数据安全
- 🤖 **AI 多模态智能免录**：拍照购物小票/发票/包装盒 OCR 识别与字段提取，自然语言一句话记账智能拆解。
- 📋 **电商订单剪贴板无感桥接**：侦测复制的淘宝、京东、拼多多商品分享文本，自动弹出卡片一键结构化快速入库。
- 🔐 **生物识别指纹/面容隐私锁**：系统原生指纹/面容锁屏验证，严密守护个人与家庭资产隐私。
- ☁️ **WebDAV 私有云安全同步**：支持坚果云、Nextcloud、群晖 Synology 等标准网盘，一键备份与多端还原。
- 📊 **多格式数据备份与导出**：一键生成带 UTF-8 BOM 的 **Excel 兼容 CSV 资产总表与流水表**，完整 JSON 本地备份。
- 🚀 **智能统一在线更新**：官方源直连优先，免重装热补丁秒级生效与全量 APK 智能回退。
