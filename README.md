# Collecter (DiaperTracker / 资产与收纳管家)

一款轻量、极简、高颜值的个人资产追踪、物品收纳空间管理、周期订阅监控与进销存统计 Android 原生客户端。

## 🌟 主要功能特性

- 📊 **资产全景看板**：支持「物品」与「订阅」双模态资产管理，展示总资产估值、拥有天数及**日均使用消费折旧成本**（元/天）。
- 🔔 **系统通知栏定时提醒**：内置周期订阅扣费预警（提前 1~3 天）、VIP 贵重物品定期核对防丢打卡与保质期到期预警。
- 🗺️ **多空间平面图与寻物地图**：支持自定义空间（家、父母家、办公室、汽车）与房间自定义编辑（阳台、书房、衣帽间等），支持图钉坐标精确标记与物品历史流转轨迹回溯。
- 📦 **物品在役 / 退役与待办归置体系**：支持闲置或老旧资产退役归置（挂闲鱼/转转代售、赠送亲友、封箱收藏、环保回收、报废），记录二手出掉回血金额。
- 🔄 **周期订阅资产管理**：纳管 iCloud、ChatGPT Plus、宽带、流媒体年卡等订阅，统一统计月均与年化支出。
- 📋 **生活流明细流水账**：按时间倒序清晰展示所有进销存记录，支持快捷修改与删除。
- 📈 **多维数据报表**：包含资产概览（分类占比色条）、资产报表（Top 5 价值品牌榜、缺货警报）与账本报表（历史年月收支透视）。
- 📊 **多格式数据导出与分享**：支持生成标准带 UTF-8 BOM 的 **Excel 兼容 CSV 资产总表与流水明细**，支持一键拉起系统分享。
- 🌓 **深浅模式自适应**：支持跟随系统、浅色模式与高定黑曜石深色模式。
- 🚀 **GitHub Releases 在线热更新**：支持多镜像加速检测下载，后台静默预缓存与 0 秒极速秒装。

## 🛠️ 技术栈

- **Language**: Kotlin 1.9
- **Platform**: Android SDK 34 (MinSDK 26, TargetSDK 34)
- **UI**: Material Components 3, ViewBinding, Canvas 自定义视图绘制
- **Storage**: 完全本地离线存储（SharedPreferences + JSON）
- **Architecture**: 零第三方冗余依赖，极致轻量（~5MB）
