# DiaperTracker (Collecter / 纸尿裤记账)

一款轻量、简洁、高效的纸尿裤及母婴耗材库存记账与消耗统计 Android 客户端。

## 🌟 主要功能特性

- 📊 **库存资产看板**：直观展示总库存、累计花费及各品牌在不同尺码下的库存进度。
- 🏷️ **自定义尺码与分类管理**：支持 NB ~ XXXL 等预设尺码，支持自由新增自定义分组、上下移动排序及重置预设。
- ⚡ **极速记一笔**：品牌自动联想、数量步进调节、单价记录与本次金额实时计算预览。
- 📋 **生活流明细**：按时间倒序清晰展示所有进销存记录，支持单条删除。
- 📈 **数据报表**：包含资产概览（库存、总花费、日均消耗）、当月统计与历史月份汇总。
- 🌓 **深浅主题切换**：支持跟随系统、浅色模式与深色模式。
- 🔄 **GitHub Releases 在线热更新**：支持应用内一键检测新版本、下载更新与自动调起安装器。

## 🛠️ 技术栈

- **Language**: Kotlin 1.9
- **Platform**: Android SDK 34 (MinSDK 26)
- **UI**: Material Components 3, ViewBinding
- **Storage**: SharedPreferences + JSON Serialization
